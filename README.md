# CarbonRhythm

CarbonRhythm is a rhythm "minigame" mod built for Need for Speed: Carbon

---

## Features

- 6-lane rhythm input system
- Car animations
- Beat-synced scrolling notes
- Judgement system (Perfect / Good / Bad / Miss)
- Combo and multiplier system
- Accuracy calculation
- Custom beatmap support
- Visual overlay with animated UI elements

---

## Build Requirements

The following dependencies are required to build:

- Microsoft Visual Studio
- DirectX 9 SDK (June 2010)
- BASS Audio Library
- MinHook (included - header + lib)
- nlohmann/json (single header included)

---

## External Dependencies

Included in `/External`:

- MinHook (header + x86 lib)
- json.hpp
